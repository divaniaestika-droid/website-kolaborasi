Sistem Persamaan Linear Dua Variabel (SPLDV)

Tentang Kolaborasi Ini

Apa itu SPLDV?

Sistem Persamaan Linear Dua Variabel (SPLDV) merupakan sistem persamaan yang disusun oleh dua persamaan linear dengan dua variabel (misalnya x dan y) dan setiap variabelnya berpangkat satu. Catatan: variabel yang digunakan tidak hanya x dan y, tetapi dapat menggunakan pasangan huruf lain, misalnya p dan q, atau huruf lainnya.

  • 🧮 Menghitung jumlah bahan yang diperlukan
  • 💰 Mengoptimalkan biaya produksi untuk setiap produk
  • 📊 Menganalisis efisiensi penggunaan limbah dalam berbagai varian lampu
  • ⚖️ Menyeimbangkan proporsi bahan untuk hasil optimal

Poster SPLDV Kami

SPLDV: Divania Estika Etiningtiyas

Penyelesaian SPLDV

Variabel

x = Harga satu pot tanaman

y = Harga satu kipas angin smart

Persamaan

4x + 5y = 475.000

5x + 4y = 425.000

Metode Campuran

1. Eliminasi

4x + 5y = 475.000 | × 4

5x + 4y = 425.000 | × 5

16x + 20y = 1.900.000

25x + 20y = 2.125.000

-9x = -225.000

x = 225.000 : 9

x = 25.000

2. Substitusi

4x + 5y = 475.000

4(25.000) + 5y = 475.000

100.000 + 5y = 475.000

5y = 475.000 - 100.000

5y = 375.000

y = 375.000 : 5

y = 75.000

Kesimpulan

Jadi, harga satu pot tanaman adalah Rp25.000 dan harga satu kipas angin smart adalah Rp75.000.

SPLDV: Lucky Cahaya Putra

Metode Campuran SPLDV

Variabel

x = Harga satu Keylight

y = Harga satu Lumiclock

Persamaan

x + 3y = 130.000

3x + 7y = 330.000

Metode Campuran

1. Eliminasi

x + 3y = 130.000 | × 7

3x + 7y = 330.000 | × 3

7x + 21y = 910.000

9x + 21y = 990.000

-2x = -80.000

x = 80.000 : 2

x = 40.000

2. Substitusi

x + 3y = 130.000

40.000 + 3y = 130.000

3y = 130.000 - 40.000

3y = 90.000

y = 90.000 : 3

y = 30.000

Kesimpulan

Jadi, harga satu Keylight adalah Rp40.000 dan harga satu Lumiclock adalah Rp30.000.

SPLDV: Lutfiana Safitri Wulandari

Penyelesaian SPLDV

Variabel

x = Harga satu EcoGlow Lamp

y = Harga satu Reglow Tree

Persamaan

2x + 5y = 415.000

5x + 2y = 355.000

Metode Campuran

1. Eliminasi

2x + 5y = 415.000 | × 2

5x + 2y = 355.000 | × 5

4x + 10y = 830.000

25x + 10y = 1.775.000

-21x = -945.000

x = -945.000 : -21

x = 45.000

2. Substitusi

2x + 5y = 415.000

2(45.000) + 5y = 415.000

90.000 + 5y = 415.000

5y = 415.000 - 90.000

5y = 325.000

y = 325.000 : 5

y = 65.000

Kesimpulan

Jadi, harga satu EcoGlow Lamp adalah Rp45.000 dan harga satu Reglow Tree adalah Rp65.000.
